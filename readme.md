# 📝 Sticky Wall - To Do Notes App

## ✨ Overview

**Sticky Wall** is a simple and interactive To-Do Notes web application.  
Users can **add, view, and delete notes** in a dynamic and visually organized way using **Bootstrap** and **JavaScript**.  
Each note is displayed as a card on the wall, making it easy to manage tasks and ideas.

---

## 🚀 Features

- **Add a new note** with a title and body.
- **Delete existing notes** easily.
- **Responsive design** using Bootstrap grid system.
- **Dynamic UI updates** without refreshing the page.
- **Modal form** for adding new notes.

---

## 🛠️ Technologies Used

- **HTML5** – for structure
- **CSS3** and **Bootstrap 5** – for styling and layout
- **JavaScript** – for dynamic functionality
- **FontAwesome** – for icons

---

## 🎯 How to Use

1. Open the project in a web browser.
2. Click the ** button** to open the modal for adding a new note.
3. Enter a **title** and **body** for your note.
4. Click **Add** to save the note.
5. Your note will appear on the sticky wall.
6. Click ** Delete** on a note to remove it from the wall.
