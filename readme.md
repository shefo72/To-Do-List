# 📝 Sticky Wall - To Do Notes App

## ✨ Overview

**Sticky Wall** is a simple, interactive, and visually engaging **To-Do Notes** web application.  
Users can **add, view, edit, and delete notes** in a dynamic way using **Bootstrap** and **JavaScript**.  
Each note is displayed as a colorful card on the wall, making task management and idea organization simple and fun.

---

## 🚀 Features

- **Add, edit, and delete notes** with a title, body, and tag.
- **Mark tasks as completed** with a checkbox.
- **Track progress** dynamically with a progress bar showing completed vs total notes.
- **Responsive, color-coded design** with dark mode via Bootstrap.
- **Real-time UI updates** without needing to refresh the page.
- **Persistent storage** using LocalStorage so notes remain on page reload.
- **Drag & drop notes** to rearrange them on the wall.
- **Search functionality** to quickly find specific notes.
- **Organize notes** with tags and add new tags dynamically.

## 🛠️ Technologies Used

- **HTML5** – for structure
- **CSS3** and **Bootstrap 5** – for styling and layout
- **JavaScript** – for dynamic functionality
- **FontAwesome** – for icons
- **Notyf.js** – for notifications
- **SortableJS** – for drag-and-drop functionality

---

## 🎯 How to Use

1. Open the project in a web browser.
2. Click the **Add Note (+)** button to open the modal.
3. Enter a **title**,**body** and **label** for your note and click **Add**.
4. **Mark a note as completed** by checking the checkbox.
5. **Delete a note** by clicking the delete icon (❌)
6. **Edit a note** by clicking the edit icon (📝)
7. Track your progress using the **dynamic progress bar**.
